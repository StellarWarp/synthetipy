# PDXLang Patcher

**为 Stellaris Mod 开发提供类似编译器的 Python 工具链**

---

## 🎯 项目目标

将 Stellaris Mod 开发从**文本操作**升级到**元编程**，让你可以用 Python 代码直接操作游戏对象。


---

## 🏗️ 架构设计

```
┌─────────────────────────────────────────────────────┐
│                 Python 用户代码                      │
│  for b in project.buildings: b.cost.minerals *= 0.8 │
└─────────────────┬───────────────────────────────────┘
                  │
                  ↓
┌─────────────────────────────────────────────────────┐
│            对象模型 (Object Model)                   │
│  ScriptedTrigger, ScriptedEffect...                 │
└─────────────────┬───────────────────────────────────┘
                  │
                  ↓
┌─────────────────────────────────────────────────────┐
│              AST (抽象语法树)                         │
│  Object, Property, Block, Value, Condition...       │
└───────────┬─────────────────────────┬───────────────┘
            │                         │
            ↓                         ↓
┌───────────────────────┐   ┌────────────────────────┐
│  Parser (语法分析器)   │   │ CodeGenerator (代码生成)│
│  Token → AST          │   │ AST → Paradox Script   │
└───────────┬───────────┘   └────────────────────────┘
            │
            ↓
┌───────────────────────┐
│  Lexer (词法分析器)    │
│  Text → Tokens        │
└───────────────────────┘
```
